ATM System Project

A C++ implementation of an ATM and Bank Management System

Project Overview

This is a comprehensive ATM and Bank Management System implemented in C++. The system provides both ATM and Bank Management functionalities, allowing users to perform various banking operations.

User Management

Create new accounts, manage user records, and handle user authentication.

ATM Operations

Check balance, deposit money, withdraw funds, and transfer money between accounts.

Bank Management

Comprehensive bank management system with admin controls and user record management.

void bank::new_user() {
    ofstream file;
    file.open("users.txt", ios::app);
    cout << "Enter Name: ";
    cin >> name;
    cout << "Enter Address: ";
    cin >> address;
    cout << "Enter Phone: ";
    cin >> phone;
    cout << "Enter Email: ";
    cin >> email;
    cout << "Set PIN: ";
    cin >> pin;
    balance = 0; // Default balance for a new user

    file << name << " " << address << " " << phone << " " << email << " " << pin << " " << balance << "\n";
    file.close();
    cout << "\nUser registered successfully!";
}
